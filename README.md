# MATH_PRO-Learn

Самодостаточный репозиторий для изучения математики и Python с ИИ-наставником. Нет интерфейса и
кода продукта: только карта программы, банк задач, протоколы и **журнал практики**. Любой
независимый ИИ-агент, открыв репозиторий, начинает с [AGENTS.md](AGENTS.md) и знает, как здесь работать.

## Как пользоваться

Открой репозиторий в ИИ-агенте (Claude Code и т. п.) и пиши обычными фразами:

| Что сказать | Что произойдёт |
|---|---|
| «сегодня 12 12, время 11 00, давай на сегодня какую-нибудь сложную задачу» | агент создаёт сессию, подбирает задачу на границе твоих возможностей и ведёт в сократическом режиме |
| «время 14 00, закрывай сессию, я всё. Результат такой-то, наблюдения такие-то» | агент фиксирует чат, файлы, наблюдения, обновляет карту компетенций и очередь повторений |

**Наставник не решает за тебя**: вместо ответов — вопросы и лестница подсказок
([docs/TUTOR-PROTOCOL.md](docs/TUTOR-PROTOCOL.md)).

## Этапы

1. **Анализ компетенций** — [docs/ASSESSMENT.md](docs/ASSESSMENT.md). Определяет уровень по 18 разделам и Python, чтобы не начинать с лишнего. Статус — `learner/state.yaml: phase`.
2. **Обучение** — по ступеням `curriculum/tree.yaml` (7 ступеней, 270 тем) от границы, найденной на этапе 1. Режимы: `challenge`, `learn`, `review`, `free`.

Первый шаг прямо сейчас: *«сегодня <дата>, время <время>, давай диагностику»*.

## Устройство

```
AGENTS.md              правила и зоны записи для агентов
docs/                  протоколы: SESSION-OPEN, TUTOR-PROTOCOL, SESSION-CLOSE, ASSESSMENT, LOGGING-STANDARD, PEDAGOGY, ARCHIVE
docs/reference/        таксономия, спецификация диагностики, педагогические заметки (из старого этапа)
curriculum/tree.yaml   карта программы и пререквизиты
curriculum/lessons/    готовые материалы по 35 темам ступеней 1–3 (справка для агента; ученику не выдаются как решение)
bank/                  банк задач (22 источника, лицензии в SOURCE.yaml); поиск: bank/tools/search_items.py
learner/               состояние ученика: фаза, карта компетенций, очередь повторений, журнал задач
journal/               журнал практики: папка на каждую сессию + INDEX.md
templates/, tools/     шаблоны и tools/journal.py (заготовка и проверка сессии)
```

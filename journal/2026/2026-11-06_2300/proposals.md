# Предложения и дефекты

1. **Незамёрженные PR как слепое пятно.** В `main` журнал и `learner/` пусты, но открытые PR #1, #2, #3 содержат три прежние сессии (2026-10-21 x2 версии, 2026-10-24). Агент, читающий только `main`, не видит `problems-seen` из тех сессий и дублирует зонды — в этой сессии так продублировалась задача ratio «+20% → −20%» (уже была в PR #2). Предложение (режим maintainer): слить или явно отклонить PR #1–#3 и решить, какая из двух версий диагностики 2026-10-21 — источник истины для `competency-map.yaml` (у PR #1 и PR #2 разные proven_level по num/frac/ratio).
2. **Формат зонда и пропуск.** В этой сессии 8 из 17 зондов пропущены без попытки; по протоколу подсказки в диагностике запрещены, поэтому данных о границе «с подсказкой» по этим разделам нет. Предложение: после обзора лесенку по пропущенным разделам начинать на 1–2 ступени ниже зонда, а не с повторения того же зонда.
3. Дефектов в задачах банка в этой сессии не выявлено: все задачи agent-generated, ответы проверены кодом до выдачи.

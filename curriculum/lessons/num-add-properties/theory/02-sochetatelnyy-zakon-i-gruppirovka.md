:::hook
На том же складе поставку разложили по трём стеллажам: 7 коробок, 3 коробки и 8 коробок.
Кладовщик считает так: сначала 7 и 3, потом прибавляет 8. Напарник складывает иначе: сначала 3 и 8.
Получат ли они разные итоги?
:::

Посчитаем первым способом: семь и три дают десяток, к десятку прибавляем восемь — 18. Теперь вторым:
три и восемь дают 11, к одиннадцати прибавляем семь — 18. Итог один и тот же: сумма трёх слагаемых
не зависит от того, какие два слагаемых сложили первыми.

**Новое обозначение: скобки.** Когда слагаемых три, их записывают подряд, а скобками отмечают,
какие два слагаемых складывают первыми:

$$
(7 + 3) + 8 \qquad \text{и} \qquad 7 + (3 + 8)
$$

В обеих записях складываются те же числа — 7, 3 и 8, — и обе дают 18. Скобки здесь не команда
вычислить по-новому, а пометка о порядке счёта.

**Сочетательный закон сложения.** Группировка слагаемых не меняет сумму:

$$
(a + b) + c = a + (b + c)
$$

Слово «сочетательный» означает «соединяющий в пары»: закон разрешает соединить слагаемые в пару
так, как удобнее. В объединённой группе от перестановки пар ничего не теряется и не добавляется.

:::example{title="Пример 1. Три стеллажа, две группировки"}
Даны 7, 3 и 8 коробок. Считаем двумя способами.

1. Первый способ: $(7 + 3) + 8$. Семь и три дают десяток, десять плюс восемь — 18.
2. Второй способ: $7 + (3 + 8)$. Три и восемь дают 11, семь плюс одиннадцать — 18.
3. Оба способа приводят к 18.

Проверка третьим способом: сначала $8 + 3 = 11$, затем $11 + 7 = 18$. Итог тот же, значит выбор пары
меняет только удобство счёта, но не результат.
:::

:::example{title="Пример 2. Пара до десятка считается первой"}
Вычислим $6 + 7 + 4$ устно.

1. Ищем удобную пару: $6 + 4 = 10$ — получился десяток.
2. По сочетательному закону: $(6 + 4) + 7 = 10 + 7$.
3. Итог — 17.

Проверка: сложим подряд — $6 + 7 = 13$, затем $13 + 4 = 17$. Итог совпал: группировка была удобнее,
но не обязательной.
:::

:::example{title="Пример 3. Десяток прячется в середине"}
Нужна сумма $4 + 2 + 8$.

1. Пара до десятка здесь — $2 + 8 = 10$; это второе и третье слагаемые.
2. Запишем $4 + (2 + 8) = 4 + 10$.
3. Итог — 14.

Проверка: посчитаем в записанном порядке — $4 + 2 = 6$, затем $6 + 8 = 14$. Пара до десятка не
обязана стоять в начале записи: её ищут среди любых двух слагаемых.
:::

:::qa
В таблице для суммы $7 + 3 + 8$ промежуточная сумма равна 10. Почему после этого остаётся один шаг?
---
Пара 7 и 3 уже сложена в десяток, а третье слагаемое ещё не учтено. Значит, остаётся прибавить к
десяти только 8: $10 + 8 = 18$. Итог больше промежуточной суммы, потому что восьмёрка ненулевая.
:::

:::note{kind=warn title="Промежуточная сумма тоже считается" error=E-num-add-properties-regroup-loses-ten}
Если ответ получился на единицу меньше (например, $7 + 3 + 8 = 17$), значит промежуточный десяток
посчитан верно, а при переходе к третьему слагаемому потерян один шаг. Проговаривайте каждую
промежуточную сумму: $7 + 3 = 10$, затем $10 + 8 = 18$.
:::

:::qa
Зачем группировать слагаемые, если итог всё равно одинаковый?
---
Удобная группировка уменьшает число шагов устного счёта: вместо досчёта по одному находятся пары,
которые сразу дают десяток или круглое число. Так $8 + 7 + 2$ считается как $(8 + 2) + 7 = 10 + 7$.
:::

:::summary
Если слагаемых три, скобки показывают, какие два складывают первыми. Сочетательный закон
утверждает, что от такой группировки сумма не меняется: $(a + b) + c = a + (b + c)$. Поэтому пару
слагаемых выбирают по удобству — обычно ту, что даёт десяток. Все слагаемые при этом обязаны
попасть в сумму ровно по одному разу. Проверка одна: посчитать сумму в записанном порядке и
сравнить итоги.
:::

:::keycard
- $(a + b) + c = a + (b + c)$: группировка слагаемых сумму не меняет
- Скобки отмечают, какие два слагаемых складывают первыми
- Удобная пара — та, что даёт десяток или круглое число
- Проверка: сложите слагаемые в записанном порядке — итог должен совпасть
:::

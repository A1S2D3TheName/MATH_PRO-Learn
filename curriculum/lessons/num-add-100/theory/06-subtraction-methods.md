:::hook
Как убедиться, что вычитание по частям и обмен десятка описывают одно удаление?
::: 

Это дополнительная мастерская после основного маршрута, а не новый обязательный способ вычисления. Работайте с клавиатуры: сначала запишите прогноз и короткую причину, затем откройте разбор. Если расхождение возникло на первом шаге, исправьте именно его, прежде чем считать дальше. Упражнения не ограничены таймером; шестнадцать минут — ориентир для чтения, самостоятельных записей и сверки.

:::example{title="Разбор 1: 54 - 26"}
Начните с вопроса, какие части удобно удержать в записи. Развёртка $54 - 20 - 6$ сохраняет все исходные части; она не добавляет новых предметов и не удаляет их сверх условия.

1. Исходное действие — $54 - 26$.
2. Запись по частям: $54 - 26 = 54 - 20 - 6$.
3. После последовательного счёта получаем $28$.

Проверка другим действием: $28 + 26 = 54$. Она восстанавливает исходное количество, а не лишь повторяет последнюю цифру ответа.
:::

:::qa
Для $64 - 23$ определите необходимость обмена до вычисления. Запишите уменьшаемое двумя частями, затем удалите единицы и десятки. Сверьте результат с вычитанием по частям; какой из способов вам удобнее и почему?
---
Обмен не нужен: $64 = 60 + 4$. Результат $64 - 23 = 41$. Проверка $41 + 23 = 64$. Удобство способа зависит от промежуточных шагов, а не от единственного обязательного выбора.
:::

:::qa
Из количества 70 нужно удалить 26. Сравните путь через разрядный обмен с путём, где сначала удаляют два десятка. Где в каждом описании появляются отдельные единицы?
---
$70 = 60 + 10$, затем $10 - 6 = 4$ и $60 - 20 = 40$, итог 44. По частям: $70 - 20 = 50$, $50 - 6 = 44$. В обоих случаях отдельные единицы получаем из полной связки.
:::

:::qa
Почему после разбора десятка нельзя сохранять прежнее число десятков? Приведите пример на 43 и проверьте количество до и после обмена. Не выполняйте пока вычитание.
---
Верно $43 = 30 + 13$. Если оставить четыре десятка и добавить тринадцать единиц, получится 53: количество выросло, поэтому обмен перестал быть равноценной заменой.
:::

:::qa
Вычтите 58 из 58 и затем 0 из 58. Почему ни одна из этих ситуаций не требует обмена? Объясните различие между нулевым остатком и нулевым вычитаемым.
---
$58 - 58 = 0$, $58 - 0 = 58$. В первом случае удалено всё, во втором не удалено ничего. Цифр единиц в уменьшаемом достаточно в обоих случаях.
:::

:::qa
Из 100 удаляют 8. Как представить 100 без отдельного алгоритма для сотен? Разбейте количество на 90 и 10, завершите вычисление и восстановите исходное число сложением.
---
$100 = 90 + 10$, $10 - 8 = 2$, $90 + 2 = 92$. Проверка $92 + 8 = 100$. Представление в десятках достаточно для этого случая.
:::

:::summary
Углубление связывает символическую запись с сохранением количества. Выбор шага должен иметь объяснение, а результат — независимую проверку. По одному неверному ответу нельзя надёжно восстановить ход рассуждений.
:::

:::keycard
- Перед вычитанием проверьте, достаточно ли отдельных единиц.
- Разбор десятка и вычитание по частям описывают удаление одной и той же части.
:::

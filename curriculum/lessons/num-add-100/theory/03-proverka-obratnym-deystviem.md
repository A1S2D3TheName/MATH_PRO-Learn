:::hook
Вы посчитали $53 - 28 = 35$. Но так ли это? Есть быстрый способ проверить, не решая задачу заново: воспользоваться обратным действием.
:::

Все обсуждаемые количества и результаты — от 0 до 100. Встречающиеся неверные записи — предложения для проверки, а не утверждения о верном результате.

## Что такое обратное действие

Для сложения и вычитания используем **обратное действие**:

| Действие | Обратное |
|---|---|
| сложение | вычитание |
| вычитание | сложение |

Связь действий такова: если вы сложили два числа и получили сумму, то, вычтя одно слагаемое из суммы, вы получите другое. И наоборот.

## Проверка сложения вычитанием

Вычислили: $35 + 28 = 63$.

Проверяем: $63 - 28 = 35$? Верно, получили первое слагаемое. Значит, сумма посчитана правильно.

Расставьте числа в следующем шаге записи.

```widget
type: stepper
prompt: Заполните пропущенную запись следующего шага.
steps:
  - expr: "35 + 28 = 63"
    rule: Исходные данные
  - expr: "63 - 28 = 35"
    ask: expr
    rule: Восстановили первое слагаемое
alt: Показана сумма; в следующей строке нужно заполнить проверку обратным действием.
caption: Развёрнутая запись помогает проследить сохранение количества.
minutes: 2
```

:::qa
Какое число должна восстановить проверка?
---
Первое слагаемое: $35$.
:::


:::example{title="Пример 1. Проверка суммы: 47 + 36 = 83"}
**Вычислили:** $47 + 36 = 83$.

**Проверка вычитанием:** $83 - 36 = 47$. Получили первое слагаемое.

Результат совпадает — сумма верна.
:::

## Проверка вычитания сложением

Вычислили: $61 - 28 = 33$.

Проверяем: $33 + 28 = 61$? Верно, получили исходное уменьшаемое. Значит, разность посчитана правильно.

:::example{title="Пример 2. Проверка разности: 80 − 47 = 33"}
**Вычислили:** $80 - 47 = 33$.

**Проверка сложением:** $33 + 47 = 80$. Получили исходное число.

Результат совпадает — разность верна.
:::

## Что делать, если проверка не прошла

Допустим, вы посчитали $53 - 28 = 35$.

Проверяете: $35 + 28 = 63$. Но исходное число было 53, а не 63. Значит, где-то ошибка.

Пересчитаем заново: $53 - 28$.

Единицы: трёх единиц недостаточно. Занимаем десяток: $53 = 40 + 13$.

$13 - 8 = 5$, десятков $4 - 2 = 2$.

Правильный ответ: $25$.

Проверяем: $25 + 28 = 53$. ✓ Теперь совпало.

:::example{title="Пример 3. Ошибка найдена проверкой"}
**Посчитали (с ошибкой):** $72 - 35 = 47$.

**Проверка:** $47 + 35 = 82$, а не 72. Не совпало!

**Пересчитываем:** $72 - 35$: единицы двух единиц недостаточно, занимаем десяток: $60 + 12$. $12 - 5 = 7$, $6 - 3 = 3$.

**Правильный ответ:** $37$.

**Проверка:** $37 + 35 = 72$. ✓
:::

:::note{kind=warn title="Проверяйте, а не повторяйте то же действие" error=E-num-add-100-check-skip}
Если снова сложить $25 + 37$ тем же способом, можно повторить прежнюю ошибку. Для проверки сложения используйте вычитание, для проверки вычитания — сложение.
:::

:::qa
Какое обратное действие подходит для проверки $46 + 27 = 73$?
--- 
Вычитание. Отнимите одно из слагаемых из суммы: $73 - 27 = 46$ (или $73 - 46 = 27$). Если получилось другое слагаемое — ответ верный.
:::

:::qa
Почему обратное действие помогает проверить результат?
--- 
При повторении прежнего способа можно повторить прежнюю ошибку, хотя это не неизбежно. Обратное действие ставит другую цель: восстановить исходное число. Оно тоже требует аккуратного вычисления. Повторный счёт другим способом также полезен, но здесь тренируем связь сложения и вычитания.
:::

:::summary
Сложение проверяем вычитанием, а вычитание — сложением. Если после обратного действия получается исходное число — ответ верный. Если не получается — в вычислении ошибка, и задачу нужно пересчитать. Обратное действие — быстрая и надёжная проверка.
:::

:::keycard
- Проверка суммы: $35 + 28 = 63$ подтверждается равенством $63 - 28 = 35$
- Проверка разности: $61 - 28 = 33$ подтверждается равенством $33 + 28 = 61$
- Если проверка не совпала, проверьте и исходное, и проверочное вычисление
- Обратная проверка восстанавливает исходные данные другим действием
:::

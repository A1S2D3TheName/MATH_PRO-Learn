# Источники

Пакет `geom-basic-shapes` написан заново по материалам из `mapping/geom.yaml` (запись темы,
`coverage: full`). Из источников взяты идеи, порядок изложения, модели и типы заданий; текст
учебников не копировался, дословно не перенесено ни одного абзаца. Числа, сюжеты, имена и
формулировки всех задач новые; каждый ответ пересчитан в `verify.py`. Все три источника
распространяются только для некоммерческого использования; ниже для каждого указаны атрибуция из
`sources/<источник>/SOURCE.yaml`, лицензия и внесённые изменения.

licensed under CC BY-NC 4.0 (учительские гайды, © 2024). Не является продуктом или одобрением

Изменения: материал пересказан по-русски для взрослого, рамка урока (разминки, работа в группах,
карточки) убрана, градусы и транспортир не используются (они в теме `geom-measure`).

1. `im-k5:im-g4-u7-l2` — Illustrative Mathematics. «Points, Lines, Rays, and Segments». 2024.
   https://im.kendallhunt.com/k5/teachers/grade-4/unit-7/lesson-2/preparation.html — взяты признаки

   «длину луча можно измерить». Переработано: определения T01, сортировка «Отрезок, луч или прямая»
   по числу концов, задача P-01 (лишняя карточка — кривая линия), вопрос T01 о длине луча.
2. `im-k5:im-g4-u7-l3` — Illustrative Mathematics. «Two or More Lines». 2024.
   https://im.kendallhunt.com/k5/teachers/grade-4/unit-7/lesson-3/preparation.html — взяты
   пересекающиеся и никогда не пересекающиеся прямые, проверка продолжением прямых, признак
   «расстояние между прямыми не меняется / уменьшается», невозможность провести прямую, не пересекающую

   признаком «просвет в клетках», углубление «Третья прямая не обойдёт обе», ошибки каталога

## Написано автором

Эти части в источниках отсутствуют или опираются на непройденный материал (градусы, транспортир,
многоугольники), поэтому написаны самостоятельно:

1. Связь фигур с числовым лучом из пререквизита `num-line`: отметки на отрезке и луче, направление
   луча $OA$ по координатам, общая часть отрезка и луча (T01; P-02…P-04, P-07…P-09, R-01, R-02,
   F-01, задачи контрольной).
2. Количественный признак пересечения по просвету в клетках и сторона, с которой прямые сойдутся
   (T04; P-06, R-06, EA-06, EB-06, EA-07, EB-07). В IM есть только качественное «расстояние не
   меняется».
3. Модели для видов углов без градусов: циферблат (стрелки в целые часы) и стороны света (T03;
   P-15…P-19, R-04, задачи контрольной).
4. Раздел T05 и задачи P-10, P-20…P-30: перебор пар без пропусков и повторов, перекрёстки улиц двух
   направлений, три точки на одной прямой, лучи с началом в отмеченных точках.
5. Модель прямого угла из сложенного листа и объяснение, почему сгиб даёт прямой угол (T03).
6. Восемь записей каталога ошибок `E-geom-basic-shapes-…` в `errors/catalog.yaml`: механизмы
   подобраны автором и проверены вычислением; частота этих ошибок у учащихся не исследовалась.

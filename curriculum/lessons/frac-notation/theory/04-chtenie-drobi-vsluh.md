:::hook
Диктор читает рецепт: «добавьте три четвёртых стакана муки». Запись в книге выглядит
как $\frac{3}{4}$. Как по записи получить слова, а по словам — запись?
:::

Чтение дроби строят из двух частей. Сначала называют числитель — сколько долей взято.
Потом называют саму долю по знаменателю — какого размера эти доли. Для одной доли
говорят «одна вторая», «одна третья», «одна четвёртая». Для нескольких долей числитель
называют обычным числом, а имя доли ставят во множественном числе: «две пятых»,
«три седьмых», «пять десятых».

Имена долей по знаменателю собраны в таблице. Левый столбец — знаменатель, средний —
одна доля, правый — несколько долей с примером числителя.

| Знаменатель | Одна доля | Несколько долей |
|---|---|---|
| 2 | одна вторая | три вторых |
| 3 | одна третья | две третьих |
| 4 | одна четвёртая | три четвёртых |
| 5 | одна пятая | четыре пятых |
| 6 | одна шестая | пять шестых |
| 7 | одна седьмая | две седьмых |
| 8 | одна восьмая | семь восьмых |
| 9 | одна девятая | четыре девятых |
| 10 | одна десятая | девять десятых |
| 11 | одна одиннадцатая | шесть одиннадцатых |
| 12 | одна двенадцатая | пять двенадцатых |

Для знаменателей больше 12 имя доли строят так же: порядковое слово от числа
знаменателя. Например, $\frac{1}{20}$ — «одна двадцатая», $\frac{3}{20}$ — «три двадцатых».

Чтение не зависит от того, больше дробь единицы или меньше. Дробь $\frac{7}{3}$ читают
«семь третьих» — так же, как читали бы «две третьих», только числитель больше.
Количество при этом больше целого: семь долей по одной третьей — это два целых
и ещё одна треть.

Обратная задача — записать дробь по названию. Слушаем название по частям: последнее
слово называет долю и даёт знаменатель, первое слово даёт числитель. «Четыре седьмых»:
доля — седьмая, знаменатель 7; количество — четыре, числитель 4; запись $\frac{4}{7}$.

:::example{title="Пример 1. Чтение двух дробей"}
Прочитаем вслух $\frac{2}{5}$ и $\frac{4}{9}$.

1. $\frac{2}{5}$: числитель 2, доля по знаменателю 5 — пятая. Читаем «две пятых».
2. $\frac{4}{9}$: числитель 4, доля по знаменателю 9 — девятая. Читаем «четыре девятых».

Проверка: в первом названии слово «пятых» возвращает знаменатель 5, слово «две» —
числитель 2. Во втором «девятых» даёт 9, «четыре» даёт 4. Название и запись
соответствуют друг другу.
:::

:::example{title="Пример 2. Единичная дробь и дробь больше единицы"}
Прочитаем $\frac{1}{6}$ и $\frac{5}{2}$.

1. $\frac{1}{6}$: числитель 1, доля шестая. Читаем «одна шестая».
2. $\frac{5}{2}$: числитель 5, доля вторая. Читаем «пять вторых».

Проверка: «пять вторых» — пять долей по половине. Две половины дают целое, четыре
половины — два целых, пять половин — больше двух целых. Числитель 5 больше
знаменателя 2, количество действительно больше единицы.
:::

:::example{title="Пример 3. Запись по названию"}
Запишем дробь по названию «три восьмых».

1. Доля названа словом «восьмых»: целое разделено на 8 частей, знаменатель равен 8.
2. Количество названо словом «три»: взято 3 доли, числитель равен 3.
3. Получаем запись $\frac{3}{8}$.

Проверка: читаем запись обратно — числитель 3, доля восьмая, «три восьмых».
Название совпало с исходным.
:::

:::note{kind=warn title="Дробь не читают как двузначное число" error=E-frac-notation-concat}
Запись $\frac{3}{8}$ иногда произносят «тридцать восемь» или «три восемь». Так теряется
дробная черта, а с ней и смысл деления: $\frac{3}{8}$ — это «три восьмых», три доли
размера в одну восьмую, а не число 38. Произносите оба слова названия: количество
и размер доли.
:::

Передвиньте ползунок от пустой полоски до количества, которое называется «три седьмых».

```widget
    filled: 0

caption: Название дроби задаёт число выбранных частей и размер каждой части.

```

:::qa
Как читается дробь $\frac{6}{10}$?
---
«Шесть десятых»: числитель 6, доля по знаменателю 10 — десятая, во множественном числе.
:::

:::qa
Как записать дробь «четыре седьмых» цифрами?
---
$\frac{4}{7}$: доля «седьмая» даёт знаменатель 7, количество «четыре» даёт числитель 4.
:::

:::summary
Дробь читают, называя сначала числитель, а потом имя доли по знаменателю.
Одна доля звучит как «одна вторая» или «одна шестая», несколько долей — как «две пятых» или «три седьмых».
По названию запись восстанавливают в обратном порядке: имя доли даёт знаменатель, первое слово — числитель.
:::

:::keycard
- Чтение: числитель, затем имя доли по знаменателю.
- Одна доля: «одна …-ая»; несколько долей: «… …-ых».
- Запись по названию: доля — знаменатель, количество — числитель.
:::

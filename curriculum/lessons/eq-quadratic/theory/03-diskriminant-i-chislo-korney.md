:::hook
У $(x-3)^2=0$ есть одно решение, у $(x-3)^2=4$ — два, у $(x-3)^2=-4$ — ни одного. Можно ли увидеть эту развилку сразу по коэффициентам?
:::

В T02 получено равносильное уравнение $(2ax+b)^2=D$ при $a\ne0$, где $D=b^2-4ac$. Поскольку $2a\ne0$, каждому значению $2ax+b$ соответствует ровно одно $x$:

- $D>0$: два различных действительных корня;
- $D=0$: один различный действительный корень $x=-b/(2a)$;
- $D<0$: решений нет, ведь квадрат действительного числа неотрицателен.

При $D=0$ одно число получается в обеих ветвях формулы. Его называют **двойным корнем**, или корнем кратности 2: $x_1=x_2$. Различное значение одно; две записи с учётом кратности — другое соглашение о счёте.

:::example{title="Пример 1. Положительный дискриминант"}
Для $2x^2-5x+2=0$ имеем $D=25-16=9>0$: корней два. Формула даёт $x=(5\pm3)/4$, то есть $2$ и $\frac12$. Проверка: $8-10+2=0$, $\frac12-\frac52+2=0$.
:::

:::example{title="Пример 2. Граница и отсутствие корней"}
Для $x^2-6x+9=0$ дискриминант $D=36-36=0$. Двойной корень — $3$: $(x-3)^2=0$. Для $2x^2-4x+5=0$ получаем $D=16-40=-24$. После выделения квадрата $(x-1)^2=-\frac32$: это невозможно для действительного $x$. Здесь отсутствие решений доказано, а не объявлено из-за невозможности воспользоваться формулой.
:::

Предскажите число моментов в модели мяча, затем измените высоту ползунком. Модель: мяч бросили вертикально вверх с земли со скоростью $v_0$ м/с; через $t$ с он находится на высоте $v_0t-5t^2$ м ($g=10$ м/с², сопротивлением воздуха пренебрегаем, $t$ — от броска до возвращения на землю). Для заданной положительной высоты $h$ равенство $v_0t-5t^2=h$ даёт уравнение $5t^2-v_0t+h=0$ с $D=v_0^2-20h$.

:::qa
При $v_0=20$ и $h=25$ получилось $D=-100$. Что это означает?
---
Моментов нет: уравнение относительно времени не имеет действительных решений. Знак дискриминанта нужно истолковать, а не принять само число −100 за время.
:::

:::qa
Сколько различных корней при $D=0$ и зачем слово «двойной»?
---
Одно значение; оно получается дважды, с плюсом и с минусом нуля. Слово «двойной» описывает кратность, а не два разных числа.
:::

:::note{kind=warn title="Знак в дискриминанте" error=E-eq-wrong-discriminant}
Для $2x^2-3x-5=0$ правильное $D=9+40=49>0$. Ошибочное $b^2+4ac=9-40=-31<0$ действительно меняет знак и неверно обещает отсутствие корней. Правильные корни — $\frac52$ и $-1$; подстановка подтверждает оба.
:::

:::deep
:::example{title="Пример 3. Мяч: три высоты — три ответа"}
В той же идеализированной модели при скорости 20 м/с высота равна $20t-5t^2$. Для высоты 15 м получаем $5t^2-20t+15=0$, $D=100$: моменты $1$ с и $3$ с. Для 20 м: $D=0$, момент $2$ с. Для 25 м: $D=-100$, моментов нет. Проверка первых трёх моментов даёт соответственно 15, 15 и 20 м.

Выделение квадрата объясняет предел высоты без графика: $20t-5t^2=-5(t-2)^2+20\le20$. Равенство достигается только при $t=2$. Числа в модели выбраны для удобства счёта, это не точный прогноз реального полёта.
:::
:::

:::summary
Для квадратного уравнения с $a\ne0$ знак $D=b^2-4ac$ определяет число различных действительных корней. При $D>0$ их два, при $D=0$ один, при $D<0$ ни одного. При нулевом дискриминанте единственный различный корень называется двойным. Если $a=0$, квадратная формула неприменима и оставшееся равенство разбирают отдельно.
:::

:::keycard
- Далее предполагается $a\ne0$; $D=b^2-4ac$.
- $D>0$: два различных действительных корня.
- $D=0$: один различный корень $-b/(2a)$, кратность 2.
- $D<0$: действительных корней нет, поскольку $(2ax+b)^2\ge0$.
- При $a=0$, $b\ne0$ остаётся один корень $-c/b$; при $a=b=0$ нужно проверить $c$.
:::

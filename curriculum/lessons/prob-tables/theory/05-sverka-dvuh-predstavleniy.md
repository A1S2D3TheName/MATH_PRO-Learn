:::hook
В рабочем отчёте одно и то же наблюдение записано двумя способами: числами в таблице и значками в пиктограмме. Как проверить, что обе записи говорят об одном и том же?
:::

Сверка не требует нового вычислительного правила. Сначала убедитесь, что названия категорий в двух записях совпадают. Затем возьмите одну категорию и прочитайте её значение в таблице, после чего прочитайте ту же строку пиктограммы с учётом условного знака. Сравните получившиеся значения. Повторите проверку для остальных названий, которые нужны вопросу.

Порядок важен. Если начать считать значки до проверки подписи категории, можно сравнить разные строки. Если забыть ключ, число рисунков будет принято за число предметов. Если читать не ту клетку, видимый ряд значков может казаться неверным, хотя ошибка окажется в выборе строки таблицы. Поэтому при расхождении вернитесь к двум подписям клетки и условному знаку, а не исправляйте данные наугад.

В этом углублении сравнивают готовые записи. Не нужно получать общее количество по категориям или рассказывать, почему число изменилось: таких сведений в двух записях может не быть. Достаточный ответ на вопрос о расхождении — назвать категорию, две записи и показать, что они не совпадают. Если записи совпали в проверяемых строках, укажите соответствующую клетку и пиктограмму.

:::example{title="Две записи согласуются"}
В заметке о пунктах выдачи есть таблица:

| Пункт | Записано |
|---|---:|
| Север | 4 |
| Парк | 2 |
| Восток | 6 |

Рядом дана пиктограмма с ключом `◆ = 2 предмета`: у Севера стоят два знака, у Парка — один, у Востока — три.

Проверим значение для Парка. В таблице на строке «Парк» записано 2. Один полный значок при данном ключе также представляет 2 предмета. Эти записи совпадают.

Для Востока таблица показывает 6. Три полных знака дают счёт 2, 4, 6. Значения совпадают и в этой строке. Ту же проверку можно выполнить для Севера: в таблице стоит 4, а два знака с тем же ключом показывают 4.

Ответ на вопрос «совпадают ли эти две записи для перечисленных пунктов?» — да. Основание ответа конкретное: для каждой проверенной подписи значение в клетке таблицы совпало с количеством, прочитанным по знакам.

Проверка: ключ один и тот же для всех трёх категорий; ни одна строка не была сопоставлена с соседним названием.
:::

:::example{title="Находим первую различающуюся строку"}
В другой паре записей ключ пиктограммы равен `◆ = 2 предмета`.

| Пункт | Записано в таблице |
|---|---:|
| Пекарня | 8 |
| Магазин | 6 |
| Киоск | 4 |

В пиктограмме у Пекарни четыре знака, у Магазина два, у Киоска два.

Начните с Пекарни: четыре знака дают 2, 4, 6, 8 — с таблицей совпало. Для Магазина два знака дают 2, 4, а в таблице на строке «Магазин» записано 6. Здесь и находится расхождение. Киоск можно проверить отдельно: два знака дают 4, и таблица показывает 4.

Ответ: записи расходятся на строке «Магазин»: в таблице — 6, а пиктограмма с ключом 2 показывает 4. Пекарня и Киоск в этом примере совпадают.

Проверка: у Пекарни и Киоска значения, прочитанные в обоих представлениях, одинаковы. Подмена строки «Магазин» соседней строкой не объясняет найденное число.
:::

Заполните число по значкам для строки «Склад», а затем сравните его с числом в той же строке таблицы. Условный знак: `◆ = 2 предмета`.

```widget
type: table
title: Сверка записей по местам
columns: [Место, Таблица, Пиктограмма, Число по значкам]

  - [Мост, 6, "◆ ◆ ◆", null]
  - [Парк, 4, "◆ ◆", null]
  - [Склад, 8, "◆ ◆ ◆ ◆", null]
task: fill
answer:
  - {r: 2, c: 3, value: 8}
alt: "Таблица содержит строки «Мост», «Парк» и «Склад», число для каждого места и ряд ромбов. В последнем столбце пока нет прочитанных значений."
prompt: "Заполните пустую клетку числа по значкам для строки «Склад»."
caption: Сопоставляйте клетку и ряд значков с одинаковой подписью категории.

```

:::qa
Какую пару записей нужно сравнить для строки «Склад»?
---
Число 8 в клетке таблицы строки «Склад» и значение ряда из четырёх ромбов с ключом 2.
:::

:::qa
В предыдущем примере значение в строке «Магазин» не совпало. Достаточно ли сказать «пиктограмма неверна»?
---
Нет. Нужно указать обе записи: таблица сообщает 6, а два знака при ключе 2 показывают 4. Это отмечает место расхождения, не приписывая причину.
:::

:::summary
Для сверки сначала сопоставляют подписи категорий. Затем для одной категории отдельно читают клетку и ряд значков с его условным знаком. Совпадение или расхождение можно показать двумя конкретными записями. Причину расхождения по одним числам устанавливать нельзя.
:::

:::keycard
- Совместите одинаковые подписи категорий.
- Прочитайте значение в клетке и значение ряда значков по ключу.
- При расхождении назовите категорию и обе записи.
- Не подменяйте проверку догадкой о причине изменения числа.
:::

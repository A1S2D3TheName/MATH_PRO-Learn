:::hook
В списке поставок вместо чисел стоят рисунки. Как понять, сколько предметов обозначает ряд значков, если рядом записан условный знак?
:::

Пиктограмма показывает категории рисунками. Рядом указывают условный знак — сколько предметов представляет один полный значок. Сначала прочитайте подпись категории, затем ключ, после этого посчитайте значки по одному, добавляя указанное для каждого количество. Если ключ равен 1, три значка обозначают три предмета. Если ключ равен 2, два полных значка обозначают две группы по два: счёт идёт 2, 4.

На некоторых пиктограммах встречается половина рисунка. Если она нарисована как половина полного знака, она представляет половину указанного количества. При ключе 2 это один предмет. Не требуется вводить новый способ вычисления: можно назвать предметы внутри первой группы, затем внутри следующей и закончить половиной группы.

:::example{title="Один знак — один предмет"}
В списке для «Ремонта» стоят три значка `●`, а условный знак сообщает: `●` означает один предмет. Сколько предметов обозначено?

1. Находим три полных значка.
2. У каждого знак равен одному предмету, поэтому считаем: первый, второй, третий.
3. Получается три предмета.

Проверка: подпись категории и условный знак оба прочитаны до подсчёта.
:::

:::example{title="Половина полного значка"}
Для «Склада» нарисованы два полных значка и половина значка. Полный значок означает два предмета.

1. Первый полный знак даёт счёт 1, 2.
2. Второй полный знак продолжает счёт: 3, 4.
3. Половина знака представляет один предмет, значит, счёт заканчивается на 5.

Ответ — 5 предметов. Проверка: если принять половину за полный знак, получится 6; это на один предмет больше, чем показывает рисунок.
:::

:::qa
Почему половина `◆` в виджете обозначает один предмет?
---
Полный знак равен двум предметам, а изображена его половина.
:::

:::note{kind=warn title="Не прибавляйте ключ один раз" error=E-prob-tables-key-as-addend}
Два полных значка по три предмета дают счёт 3, 6. Запись «2 + 3 = 5» добавляет ключ к числу рисунков, но не повторяет группу три предмета для второго знака.
:::

:::note{kind=warn title="Половина не равна целому знаку" error=E-prob-tables-half-as-full}
При ключе 2 два полных значка и одна половина обозначают 5 предметов. Если считать половину полным знаком, получится 6; если отбросить её — 4.
:::

:::qa
У категории стоят четыре полных значка, каждый означает один предмет. Какое число записано?
---
Четыре предмета: считайте по одному на каждый из четырёх значков.
:::

:::summary
Пиктограмма использует рисунки вместо чисел по категориям. Условный знак сообщает значение полного значка. Половина значка соответствует половине его значения, если рисунок явно показывает половину. Считайте группы по очереди и не подменяйте ключ числом значков.
:::

:::keycard
- Сначала прочитайте подпись категории и условный знак.
- Полный значок обозначает количество, указанное в ключе.
- Половина значка означает половину значения полного знака.
- При счёте продолжайте от одной группы к следующей.
:::

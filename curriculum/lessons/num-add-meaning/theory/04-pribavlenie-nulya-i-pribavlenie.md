:::hook
Утро вторника в «Перроне». В витрине лежат 6 круассанов, а сегодняшняя поставка отменилась:
привезли 0. Сколько круассанов теперь в витрине? И что изменится, если бы привезли один?
:::

Два слагаемых заслуживают отдельных правил, потому что встречаются каждый день: ноль
и единица.

**Прибавление нуля.** Ноль — это ноль предметов, пустая группа. Присоединить пустую группу —
значит ничего не добавить: группа не изменится. Поэтому при любом $a$

$$
a + 0 = a
$$

На луче это прыжок длиной 0: точка не двигается.

**Прибавление единицы.** Прибавить один — значит присоединить группу из одного предмета.
На луче это ровно один прыжок вправо, а попадает он на следующее число — то самое, которое
в теме про луч называлось соседом числа:

$$
a + 1 \text{ — число, идущее сразу после } a
$$

:::qa
Почему в каждой строке таблицы столбец «$a + 0$» совпадает с первым столбцом?
---
Прибавить ноль — присоединить пустую группу, поэтому предметов не прибавляется: $a + 0 = a$
для любого числа $a$.
:::

:::example{title="Пример 1. Круассаны без поставки"}
В витрине 6 круассанов, поставка отменилась, то есть привезли 0.

1. Слагаемые — 6 и 0: к группе из шести круассанов присоединяется пустая группа.
2. Пустая группа ничего не добавляет: круассанов остаётся шесть.
3. Запись: $6 + 0 = 6$.

Проверка по лучу: прыжок длиной 0 из точки 6 оставляет точку в 6.
:::

:::example{title="Пример 2. Ещё один гость"}
В зале 4 гостя, зашёл ещё 1. Сколько гостей стало?

1. Слагаемые — 4 и 1: присоединяется группа из одного человека.
2. Прибавить один — перейти к следующему числу: после 4 идёт 5.
3. Запись: $4 + 1 = 5$.

Проверка по лучу: из точки 4 один прыжок вправо приземляется ровно в 5.
:::

:::example{title="Пример 3. Ноль на первом месте"}
Запишем случай наоборот: $0 + 3$. Первая группа пустая, во второй 3 предмета.

1. Объединяем пустую группу и группу из трёх предметов: предметов по-прежнему три.
2. Значит $0 + 3 = 3$ — ноль не «съедает» второе слагаемое, с какой бы стороны он ни стоял.
3. На луче: старт из 0 и три прыжка вправо дают 3.

Проверка: обе группы вместе — это те же три предмета, что были во второй группе.
:::

:::example{title="Пример 4. Сначала никого, потом один гость"}
Утром в зале 7 гостей. За первый час не зашёл никто, за второй пришёл ещё 1 гость.
За это время никто не ушёл.

1. Итог первого часа: $7 + 0 = 7$ — пустая группа ничего не изменила.
2. Теперь к семи гостям присоединился один: $7 + 1 = 8$.
3. Итог: 8 гостей.

Проверка по лучу: прыжок на 0 оставляет точку в 7, прыжок на 1 сдвигает её в 8.
:::

:::note{kind=warn title="Ноль ничего не съедает" error=E-num-add-meaning-zero-eats}
Ответ $6 + 0 = 0$ означал бы, что шесть круассанов исчезли оттого, что к ним ничего
не добавили. Но прибавить ноль — значит ничего не менять: шестёрка остаётся шестёркой.
Если одно слагаемое ненулевое, ответ 0 не подходит. Но $0 + 0 = 0$ верно:
обе группы пусты, и после объединения предметов по-прежнему нет.
:::

:::qa
Как с помощью соседей числа объяснить, что $9 + 1 = 10$?
---
Число, идущее сразу после 9, — это 10. Прибавление единицы всегда приводит к следующему
соседу, поэтому $9 + 1 = 10$.
:::

:::summary
Ноль — пустая группа: от прибавления нуля число не меняется, $a + 0 = a$,
и $0 + a = a$ тоже. Единица — группа из одного предмета: прибавить один значит перейти
к следующему числу на луче, то есть к соседу числа $a$. Оба правила видны на луче: прыжок
на 0 оставляет точку на месте, прыжок на 1 сдвигает её на одно деление вправо.
:::

:::keycard
- $a + 0 = a$: прибавление нуля число не меняет
- $0 + a = a$: порядок слагаемых для нуля не важен
- $a + 1$ — следующее за $a$ число, его сосед справа
:::

:::hook
Вечерняя смена. В блокноте осталась запись с утреннего счёта: «напитков было 5, привезли ещё
непустую партию, ничего не убрали, в записи итог 5». Даже без пересчёта понятно: в записи ошибка. Какое правило позволяет
поймать её мгновенно?
:::

При сложении чисел 0, 1, 2 и так далее объединённая группа содержит все предметы каждой исходной группы. Ничего не убирают. Отсюда простое правило
прикидки: **сумма не меньше каждого слагаемого.** Она равна одному из слагаемых только тогда,
когда другое слагаемое — ноль: $a + 0 = a$ и $0 + a = a$. Если ни одно слагаемое не ноль, сумма
больше каждого из них: на луче она строго правее обоих слагаемых.

:::example{title="Пример 1. Прикидка до счёта"}
Надо найти $4 + 3$.

1. Первое слагаемое 4, второе не ноль, значит сумма обязана быть больше 4.
2. На луче это точка правее 4: кандидаты 5, 6, 7, …
3. Точный счёт даёт 7 — число правее 4, прикидка сходится.

Если бы счёт дал 4 или 3, прикидка отвергла бы ответ ещё до проверки.
:::

:::example{title="Пример 2. Три ошибки в одной записи"}
Разберём запись $5 + 3$ с тремя разными неверными ответами.

1. Ответ 5: сумма совпала с первым слагаемым, хотя вторая группа не пуста; возможно, её не присоединили.
2. Ответ 7: до верного 8 не хватает одного; возможен сбой при досчёте, но по одному ответу причина неизвестна.
3. Ответ 53: цифры склеены, как в тексте; из групп в 5 и 3 предмета пятьдесят три предмета
   не получится.

Верный ответ 8 — правее обоих слагаемых на луче.
:::

Прикидка — не доказательство, а фильтр: она отбрасывает ответы, которых быть не может.
Ответ 5 для записи 5 + 3 не проходит сразу: он равен первому слагаемому, а второе слагаемое не ноль. Ответы 7 и 53 прикидке
не противоречат — они больше слагаемых, — поэтому проверка нужна и после неё: сбой на единицу
находит пересчёт, а склейку выдаёт величина ответа. Слагаемые в этой теме не больше десяти,
значит, и вместе их не больше двадцати: число 53 невозможно уже по размеру.

:::example{title="Пример 3. Сравнение без вычисления"}
Что больше: $4 + 3$ или $4 + 2$? Считать не нужно.

1. Оба движения стартуют из точки 4.
2. Первая сумма делает 3 прыжка вправо, вторая — только 2.
3. Три прыжка уводят дальше, поэтому $4 + 3$ больше, чем $4 + 2$.

Прикидка работает и здесь: обе суммы больше 4, но первая лежит на луче правее.
:::

:::qa
Почему карточка $5 + 0 = 5$ лежит в корзине «Запись верна», хотя сумма равна слагаемому?
---
Ноль — исключение: он не добавляет предметов, и группа из 5 предметов не меняется. Сумма больше первого слагаемого только тогда, когда второе не ноль.
:::

:::qa
Может ли при сложении двух чисел получиться 6, если первое слагаемое равно 7?
---
Нет. Второе слагаемое либо ноль — тогда сумма равна 7, либо больше нуля — тогда сумма больше 7.
Число 6 лежит на луче левее семерки, а сложение двигает только вправо.
:::

:::qa
Дана запись $4 + 2 = 5$. Постройте по ней модель на луче и найдите место, где запись расходится
со счётом.
---
Старт в точке 4, два прыжка вправо: 5, потом 6. Движение заканчивается в точке 6, а в записи стоит 5:
один переход потерян. Так по чужой записи можно не только посчитать, но и проверить, где она
разошлась со смыслом сложения.
:::

## Как перебрать небольшое число возможностей

Иногда нужно не найти одну сумму, а сравнить несколько результатов. Записывайте случаи
в одном порядке, чтобы ничего не пропустить. Пара — это два выбранных числа;
пары могут быть разными, а их суммы одинаковыми.

:::example{title="Пример 4. Разные пары и разные суммы"}
Возьмём числа 1, 2 и 3. Выбираем два числа; одно и то же разрешено взять дважды.
Сколько разных значений суммы получится?

1. С первым числом берём пары $1 + 1 = 2$, $1 + 2 = 3$, $1 + 3 = 4$.
2. Со вторым остаются $2 + 2 = 4$, $2 + 3 = 5$. Пару $2 + 1$ не повторяем: это те же группы, что $1 + 2$.
3. С третьим остаётся $3 + 3 = 6$. Все пары перечислены.
4. Значения: 2, 3, 4, 4, 5, 6. Четвёрка встретилась дважды, поэтому разных значений пять: 2, 3, 4, 5, 6.

Проверка: начинаем с каждого числа по очереди, а второе берём из той же позиции или правее.
Обратный порядок уже рассмотренных групп не даёт нового значения. Шесть пар — не шесть разных сумм.
:::

:::example{title="Пример 5. Сколько можно добавить максимально"}
На полке 4 коробки, а разрешено не больше 7. Какое наибольшее количество можно добавить?

1. Добавляем по одной: общее количество становится 5, затем 6, затем 7.
2. Сделаны три перехода; старт 4 новым предметом не считается. Можно добавить 3 коробки.
3. Проверяем границу: $4 + 3 = 7$. Ещё одна коробка дала бы $7 + 1 = 8$, а 8 больше 7.

Проверка: добавить 0, 1 или 2 тоже разрешено, но это не наибольшее количество.
Если бы спрашивали любое допустимое количество, единственного ответа не было бы.
:::

:::qa
Почему в переборе пар нужно проверить пару с двумя одинаковыми числами?
---
По условию число разрешено брать дважды. Если пропустить такую пару, можно потерять значение суммы.
Например, в наборе 1, 2, 3 значение 6 получается только из пары 3 и 3.
:::

:::summary
Сложение двигает счёт только вправо, поэтому сумма не бывает меньше своих слагаемых. Если ни одно
слагаемое не ноль, сумма больше каждого из них; ноль — исключение, он оставляет число на месте.
Прикидка отбрасывает невозможные ответы: меньше слагаемого, а при ненулевом втором слагаемом —
и равные первому. Верный ответ она не подтверждает: его проверяет пересчёт. Сбой на единицу
находит пересчёт, а склейку цифр выдаёт величина: сумма двух чисел до десяти не больше двадцати.
:::

:::keycard
- Сумма не меньше каждого слагаемого; если ни одно не ноль — больше каждого
- Ответ, равный первому слагаемому, возможен только при нулевом втором слагаемом
- $a + 0 = a$ — случай, когда сумма равна первому слагаемому
- Прикидка отбраковывает невозможное, но не доказывает верное: нужен пересчёт
:::

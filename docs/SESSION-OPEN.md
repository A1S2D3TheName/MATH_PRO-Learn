# Протокол открытия сессии

Срабатывает на фразу вида: *«сегодня 12 12, время 11 00, давай на сегодня какую-нибудь сложную задачу»*.

## 1. Разбор команды

Выдели из сообщения:

| Поле | Как получить | Если не указано |
|---|---|---|
| `date` | «12 12» → `ДД ММ`; год — текущий год ученика (из `learner/state.yaml: last_session_date`, иначе спроси) | спроси |
| `time` | «11 00» → `11:00` | спроси |
| `mode` | по запросу, таблица ниже | `challenge`, если фаза `learning`; `assessment`, если фаза `assessment` |
| `wish` | остальной текст (тема, длительность, настроение) | пусто |

Дату и время **не** выдумывай и не бери из системных часов. Одним вопросом уточни только недостающее.

| Запрос ученика | `mode` |
|---|---|
| «диагностика», «определи уровень», «проверь, что я знаю» | `assessment` |
| «сложную задачу», «чтоб пошевелить мозгами», «челлендж» | `challenge` |
| «новую тему», «двигаемся дальше» | `learn` |
| «повторить», «что пора освежить» | `review` |
| «поговорим», «разберём мой вопрос» | `free` |

## 2. Обязательное чтение (в таком порядке, до первого ответа ученику)

1. [AGENTS.md](../AGENTS.md) и [TUTOR-PROTOCOL.md](TUTOR-PROTOCOL.md).
2. `learner/state.yaml` — фаза, фронтир, последние сессии, открытые вопросы.
3. `learner/competency-map.yaml` — что доказано, где пробелы.
4. `learner/review-queue.yaml` — что просрочено.
5. Последние **3** записи `journal/INDEX.md`; из них — `session.md` и `observations.md` последней сессии (что было, на чём остановились, что просил попробовать в следующий раз).
6. Если `phase: assessment` — [ASSESSMENT.md](ASSESSMENT.md).
7. Если в журнале есть сессия со `status: open` — сначала закрой её по [SESSION-CLOSE.md](SESSION-CLOSE.md) (`closed_late`, время конца спроси у ученика, но не требуй точного).

## 3. Создание заготовки

```bash
python tools/journal.py open --date <YYYY-MM-DD> --time <HH:MM> --mode <mode>
```

Создаёт `journal/<год>/<YYYY-MM-DD_HHMM>/` из шаблонов с `status: open`. Дальше заполняется
по ходу занятия. Если папка уже есть (повторный запуск в ту же минуту) — добавь `-b`
к имени (`..._1100b`), не затирай.

## 4. Что отвечать ученику (по режимам)

В ответе — не больше 10 строк, без лекции:
1. Одна строка контекста: «В прошлый раз <факт из журнала>. Сейчас фронтир: <раздел/ступень>».
2. Предложение: **что**, **сколько**, **как** (формат и ограничения) — и сразу переход к делу.

### `challenge` — подбор сложной задачи
1. Определи фронтир: раздел(ы) из `competency-map.yaml`, где уровень «доказан с подсказкой» или «доказан давно»; плюс то, что в очереди повторений.
2. Найди кандидатов: `python bank/tools/search_items.py "<ключевые слова>" -k 10` и/или по `curriculum/tree.yaml`; сузь по домену из `docs/reference/TAXONOMY.md`.
3. Выбери по критериям [TUTOR-PROTOCOL.md §6](TUTOR-PROTOCOL.md). Проверь, что нет в `problems-seen.jsonl`.
4. **Реши и проверь сам (скрытно)**, лучше кодом. Не получилось надёжно — другая задача. Решение не показывай.
5. Запиши выбор и обоснование в `session.md` (раздел «План»): `item_id`, источник, почему на границе, ожидаемые приёмы, ожидаемая вероятность успеха.
6. Выдай задачу по §6 протокола наставника. На этом режим открытия закончен, дальше — наставник.

### `learn` — новая тема
Следующая тема из `curriculum/tree.yaml` по пререквизитам, не доказанная в карте. Формат: сначала 3–5 вопросов на **извлечение** (что ученик уже знает по теме — без лекции), затем 1 задача «входа», затем по необходимости короткая справка (≤ 1 экрана) только по тому, что не нашлось у ученика. Теорию не излагать заранее.

### `review` — повторение
Возьми из `review-queue.yaml` просроченные пункты (старейший первым). Проси **воспроизвести** (решить заново, объяснить, написать код) без подглядывания. Результат — в очередь.

### `assessment` — диагностика
См. [ASSESSMENT.md](ASSESSMENT.md).

### `free` — свободный
Любой запрос ученика, но те же правила наставника и ведения журнала.

## 5. Пока сессия идёт

* Веди `transcript.md` непрерывно (дозапись после каждого содержательного обмена или хотя бы каждые 5–10 реплик).
* Все файлы ученика (код, наброски) складывай в `work/`.
* Каждое событие, влияющее на оценку, помечай (см. LOGGING-STANDARD §3).
* Внезапная смена задачи/режима — запиши в `session.md` строкой «Смена: …».

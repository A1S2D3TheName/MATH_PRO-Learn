# Таксономия и карта покрытия

Раздел «таксономия» отвечает на два вопроса: **что** измеряем (домены) и
**чем** измеряем (источники). Разделы дерева MATH_PRO — в `tree.yaml`,
их отображение на источники — в `mapping/`. Здесь — только то, что добавляет
эта папка: покрытие доменов и измерений новыми материалами.

## 1. Предметные домены

| домен | что входит | ступени |
|---|---|---|
| `arithmetic` | счёт, действия, разряд, дроби, проценты, отношения | 1–2 |
| `algebra` | уравнения, неравенства, функции, тождества, параметры | 3–5 |
| `geometry` | планиметрия, стереометрия, векторы, площади и объёмы | 2–5 |
| `analysis` | пределы, производные, интегралы, ряды | 6–7 |
| `discrete` | комбинаторика, графы, алгоритмы, оценка сложности | 4–6 |
| `number-theory` | делимость, остатки, простые, диофантовы уравнения | 4–6 |
| `logic` | высказывания, предикаты, таблицы истинности, доказательства | 4–6 |
| `proofs` | структура доказательства, индукция, формализация | 5–7 |
| `nonstandard` | олимпиадные и исследовательские задачи | 5–7 |
| `probability` | классическая вероятность, комбинаторика, статистика | 4–6 |
| `python` | язык, алгоритмы, работа с данными, символьная математика | 3–6 |
| `reasoning` | общие способности: матрицы, аналогии, логика | — (контур способностей) |
| `memory` | рабочая память, удержание | — (контур способностей) |

`reasoning`, `memory`, `speed` — **не предметные домены**. Их измеряют
IQ-подобные тесты, и они не складываются с предметными баллами.

## 4. Как это соотносится с деревом MATH_PRO

Разделы `mapping/` (alg, calc, code, comb, eq, frac, func, geom, logic, model,
nt, num, numsys, olymp, param, prob, ratio, stereo, trig) — 19 штук. Новые
источники **не добавляют тем** в дерево: дерево описывает программу, а
источники — материал. Связь двусторонняя:

* источник → темы: `mapping/<раздел>.yaml` (уже существует, нужно дополнить);
* тема → источник: то, что предлагает эта папка.

Сопоставление по тегам единиц:

* `math-prm800k`: `path = [MATH, <Subject>, <split>]`, Subject ∈ {Algebra,
  Counting & Statistics, Geometry, Intermediate Algebra, Number Theory,
  Prealgebra, Precalculus}. Для `mapping/` разумная проекция: Algebra →
  `alg` и `eq`, Geometry → `geom` и `stereo`, Precalculus → `trig` и `func`,
  Number Theory → `nt`, Counting & Statistics → `comb` и `prob`.
* `ultimate-aptitude`: `tags` содержат `topic` (percentages, time-and-work,
  data-sufficiency…) и `category`.
* `treecut-math`: тема не задана (сюжеты бытовые) — годится для `num` и `alg`.
* `ai-tutor-socratic`: `concept` ∈ {number_sense, fractions_basics, ratio_basics,
  percentage, integers, …} — прямая проекция на `num`, `frac`, `ratio`.
* `forallx`: главы 1–6 → `logic`; формальная часть → `proofs`.
* `thealgorithms-python`: первый элемент `path` (каталог) → `code`.
* `exercism-python`: `kind=practice` → `code`; `kind=concept` → `code` и `model`.

## 5. Где материал дублируется и как не плодить копии

`math-prm800k` (MATH) и `math-500-ru` (тот же test-сплит, переведённый) — это
**один и тот же материал на двух языках**. Чтобы не завести две копии:

* английская версия живёт в `sources/math-prm800k/items/math-dataset.jsonl`;
* русская не копируется: в `sources/math-500-ru/items/index.jsonl` лежит
  **индекс из 500 позиций** (10 из них — preview-метаданные с `unique_id`,
  `subject`, `level`), а не тексты;
* при сборке темы выбирается **одно** из двух: английская версия с разбором
  или — если правообладатель перевода даст разрешение — русская формулировка
  с английским разбором по ключу `unique_id`.

`national-olympiads-bank` и `imosllean4` пересекаются по шортлистам ММО, но
`national-olympiads-bank` **не публикуется вообще** (лицензия прямо запрещает
копирование), поэтому дублирования материала не возникает.

## 6. Пробелы покрытия (честно)

1. **Начальный уровень (ступени 1–2) на русском.** Новые источники его не
   закрывают: MATH начинается с уровня «Prealgebra» на английском, IQ-тесты
   к предметам не относятся. Нужен отдельный русскоязычный банк арифметики.
2. **Базовые доказательства и геометрия.** `forallx` даёт теорию логики, но
   задач «докажите, что…» средней сложности нет. `minif2f` и `imosllean4` —
   верхний край.
3. **Пары для переноса.** Источники дают задачи, но не пары «исходная →
   переносная». Их нужно собирать: это ручная работа, автоматика тут не
   заменит человека (см. `specs/COVERAGE-GAPS.md`).
4. **Тайминги.** Ни один источник не содержит проверенных нормативов
   времени решения по доменам; без калибровки время остаётся флагом.
5. **Психометрическая валидация.** Ни один из банков способностей не имеет
   опубликованной психометрической проверки. `iq-measurer` прямо признаёт,
   что его «IRT-вдохновлённая» формула не является IRT.

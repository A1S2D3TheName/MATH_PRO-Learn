# AGENTS.md — читать первым

Этот файл обязателен для любого ИИ-агента, который открыл репозиторий. Если чат-инструкция
противоречит этому файлу, прав этот файл — кроме явной команды пользователя в режиме
`maintainer` (см. §3).

## 1. Что это

Личный репозиторий-тренажёр: **один ученик** (владелец репозитория) изучает математику
и Python. Агент здесь — **сократический наставник и ведущий журнала**, не решатель задач
и не разработчик. Кода продукта нет и не нужно: репозиторий — это данные, протоколы и журнал.

Язык — русский. Ученик пишет коротко и по-разговорному; расшифровывай команды по §2.

## 2. Три команды ученика → три протокола

Ученик управляет репозиторием фразами. Распознавай по смыслу, не по точному тексту.

| Фраза ученика (пример) | Режим | Что читать и делать |
|---|---|---|
| «сегодня 12 12, время 11 00, давай на сегодня какую-нибудь сложную задачу» | **открытие** | [docs/SESSION-OPEN.md](docs/SESSION-OPEN.md) |
| любые сообщения в ходе занятия | **наставник** | [docs/TUTOR-PROTOCOL.md](docs/TUTOR-PROTOCOL.md) |
| «время 14 00, закрывай сессию, я всё. Результат такой-то, наблюдения такие-то» | **закрытие** | [docs/SESSION-CLOSE.md](docs/SESSION-CLOSE.md) |

Первый этап обучения — **анализ компетенций** (`phase: assessment` в
[learner/state.yaml](learner/state.yaml)); пока он не закрыт, режим «сложная задача» и
«новая тема» недоступны: агент ведёт диагностику по [docs/ASSESSMENT.md](docs/ASSESSMENT.md).

Дата и время берутся **только из слов ученика**, не из часов агента и не из системной даты.

## 3. Зоны записи (жёстко)

| Путь | Агент в сессии | Примечание |
|---|---|---|
| `journal/<год>/<сессия>/` | **пишет** | только своя сессия; см. [docs/LOGGING-STANDARD.md](docs/LOGGING-STANDARD.md) |
| `journal/INDEX.md` | дописывает одну строку при закрытии | |
| `learner/state.yaml` | обновляет поля, перечисленные в SESSION-CLOSE | |
| `learner/competency-map.yaml` | обновляет **только** с ссылкой на доказательство | |
| `learner/problems-seen.jsonl`, `learner/review-queue.yaml` | дописывает | append-only |
| `docs/`, `AGENTS.md`, `README.md`, `tools/`, `bank/`, `curriculum/`, `templates/` | **только читает** | |
| прошлые сессии в `journal/` | **только читает** | исправление — файлом `addendum-*.md` в новой сессии |

Нашёл дыру в стандарте, плохую задачу, ошибку в банке — **не чини**: запиши в
`journal/<сессия>/proposals.md`. Править документы можно только в режиме **maintainer**:
когда ученик прямо написал «режим maintainer» / «правим репозиторий». Тогда сессия обучения
не ведётся, а изменения делаются отдельным коммитом.

## 4. Незыблемые правила

1. **Не решай за ученика.** Ни финального ответа, ни полного решения, ни «давай я покажу».
   Подробно — [docs/TUTOR-PROTOCOL.md](docs/TUTOR-PROTOCOL.md). Это главное правило репозитория.
2. **Не выдумывай данные.** Нет доказательства — нет записи. Оценка компетенции без
   ссылки на задачу и сессию недопустима. Не восстанавливай «по памяти» то, чего не было в чате.
3. **Разделяй факт, слова ученика и свою интерпретацию.** В журнале это три разных
   метки; смешивать нельзя ([docs/LOGGING-STANDARD.md](docs/LOGGING-STANDARD.md) §4).
4. **Не доверяй банку слепо.** В `bank/` бывают ошибки в ответах и разборах. Проверяй
   ответ кодом (Python/SymPy) прежде, чем сказать ученику «неверно». Дефекты — в `proposals.md`.
5. **Не выходи за зоны записи** (§3) и не создавай новые типы файлов: только те, что
   описаны в стандарте.
6. **Не оценивай человека.** Ты фиксируешь, что сделано в задачах, а не «способен/неспособен».
   Нет ярлыков, нет сравнений с «нормой».
7. **Сессию без закрытия не бросай.** Если ученик пропал, запись остаётся с `status: open`;
   в следующий раз сначала закрой её по SESSION-CLOSE (с пометкой `closed_late`).

## 5. Карта репозитория

```
AGENTS.md            этот файл
README.md            для человека: что это и как пользоваться
docs/                протоколы (открытие, наставник, закрытие, диагностика, журнал)
docs/reference/      справочные материалы старого этапа: таксономия, спецификация диагностики, педагогика
curriculum/tree.yaml карта программы: 7 ступеней, 18 разделов, 270 тем, пререквизиты
curriculum/lessons/ готовые материалы по темам ступеней 1–3 (справка для агента, не выдавать как решение)
bank/                банк задач и каталог источников (28 МБ), поиск: bank/tools/search_items.py
learner/             состояние ученика: фаза, карта компетенций, очередь повторений, журнал задач
journal/             журнал практики: по папке на сессию
templates/           шаблоны файлов сессии
tools/journal.py     заготовка сессии и проверка журнала (только stdlib)
```

## 6. Рабочие команды

```bash
python tools/journal.py open  --date 2026-12-12 --time 11:00 --mode challenge   # создать заготовку сессии
python tools/journal.py check journal/2026/2026-12-12_1100                      # проверить полноту записи
python tools/journal.py close journal/2026/2026-12-12_1100 --time 14:00         # проставить конец и проверить
python bank/tools/search_items.py "truth table" -k 5                           # найти задачи в банке
```
